## Organización

Cada práctica puede incluir:

- archivos `.pas` con las resoluciones;
- un `README.md` con la consigna o una explicación del tema;
- una carpeta `Material/` con apuntes y archivos complementarios.

La estructura está pensada para que las nuevas prácticas, partes y actividades
se incorporen sin tener que reorganizar el contenido existente.

## Cómo trabajar con los ejercicios

1. Entrar en la carpeta de la práctica correspondiente.
2. Leer la consigna y el README de esa sección, si existe.
3. Abrir el archivo Pascal del ejercicio.
4. Compilar y ejecutar el programa con un compilador compatible con Pascal,
   como Free Pascal.

Los ejercicios son independientes entre sí, salvo que la consigna indique lo
contrario.

## Próximas actualizaciones

Este repositorio se encuentra en crecimiento. En futuras actualizaciones se
agregarán nuevas prácticas, ejercicios, materiales y correcciones. Para
mantener una navegación clara:

- conservar la organización por número y tema;
- agregar cada nueva práctica dentro de `Práctica/`;
- incluir un README en las secciones que necesiten una explicación propia;
- actualizar este índice cuando se incorpore una nueva sección;
- mantener los nombres de archivos descriptivos y consistentes.

## Estado

El contenido disponible corresponde a las prácticas incorporadas hasta el

medida que se agreguen nuevos ejercicios.
